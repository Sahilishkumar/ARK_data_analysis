# ARK Donation Campaign Analysis

An Excel dashboard project to analyse ARK's donation and campaign data and understand donation patterns, campaign performance, and payment status.

## Tools and Techniques

- Microsoft Excel
- Data cleaning and formatting
- PivotTables and filters
- Charts and plots
- Interactive slicers
- Data analysis and insights

## Privacy

The original dataset contains sensitive donor information, so it cannot be made public. The project is shared without exposing private donor data.

## Analysis

The dashboard helps explore donation trends, compare campaign performance, analyse payment status, and identify patterns in donor contributions.
